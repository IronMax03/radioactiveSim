\doxysubsection{Detailed Description}
An axis-\/aligned bounding box used to score particles entering the region. 

The \doxylink{class_r_o_i}{ROI} counts each live \doxylink{class_particle}{Particle} that enters its volume and marks that particle as no longer alive so it is not counted more than once.
