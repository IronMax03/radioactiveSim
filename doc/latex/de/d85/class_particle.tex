\doxysubsection{Detailed Description}
Represents a single physical particle moving through the simulation domain. 

A \doxylink{class_particle}{Particle} carries kinematic state (position, velocity, acceleration), physical properties (mass, electric charge, type), and bookkeeping information used by the simulation loop (distance travelled inside a shield, alive flag).
