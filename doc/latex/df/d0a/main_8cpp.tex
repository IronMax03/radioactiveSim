\doxysubsection{Detailed Description}
Entry point for the radioactive particle transport simulation. 

Sets up the physical geometry (shielding, \doxylink{class_r_o_i}{ROI}, source), writes initial VTP geometry files for visualisation, then constructs and runs the \doxylink{class_simulation}{Simulation}. Execution time is measured and printed at the end.
