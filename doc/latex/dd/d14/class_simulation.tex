\doxysubsection{Detailed Description}
Top-\/level simulation driver. 

The \doxylink{class_simulation}{Simulation} class owns all physical objects (source, shielding, \doxylink{class_r_o_i}{ROI}) and the list of live particles. Calling \doxylink{class_simulation_ae5c367f87c0b5dc9740bc6d00e44e72c}{run()} advances the simulation for the configured number of time steps, handling emission, movement, shielding absorption, \doxylink{class_r_o_i}{ROI} scoring, and periodic CSV output.
