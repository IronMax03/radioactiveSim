Detailed Description

template<typename T>
struct lazy_node< T >

A lazy node for the octree data structure.

Template Parameters
TThe type of the coordinates. Must be a numeric type (int, float, double, etc.).
Note
Spatial indexing is done using morton indices, which means that the children of a node are indexed as follows: 0: lower-left-back 1: lower-right-back 2: upper-left-back 3: upper-right-back 4: lower-left-front 5: lower-right-front 6: upper-left-front 7: upper-right-front
