Detailed Description

template<typename T>
struct vector3< T >

A generic 3-D vector whose component type is T.

Template Parameters
TComponent type. Must be an integral or floating-point type (enforced via static_assert).

Supports element-wise addition, subtraction, scalar multiplication/division, dot product, Euclidean norm, normalisation, equality comparison, and stream output.

In-place component-wise multiplication (replaces each component with the dot product).

Note
Due to the implementation delegating to the scalar dot-product operator*(vector3), the resulting assignment of a scalar T to a vector3 is unusual and may not compile for all types. Prefer explicit dot-product usage where needed.
