Detailed Description

Top-level simulation driver.

The Simulation class owns all physical objects (source, shielding, ROI) and the list of live particles. Calling run() advances the simulation for the configured number of time steps, handling emission, movement, shielding absorption, ROI scoring, and periodic CSV output.
