void is_in_bounding_box ( Particle & p)

Kill a particle if it has left the global bounding box.

The global bounding box is the union of all boxes passed to write_box_vtp(). If p is outside this box its alive flag is set to false.

Write an axis-aligned box as a VTK PolyData (.vtp) file.

The box is represented as a mesh of 8 vertices and 6 quad faces. Additionally, the function tracks the global bounding box of all boxes written so far (used by is_in_bounding_box()).
