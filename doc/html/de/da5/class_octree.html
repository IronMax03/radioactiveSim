◆ calc_force()

void Octree::calc_force ( Particle & p)

Calculate the electrostatic force acting on p using the Barnes-Hut approximation and store the result in p.acceleration.

Compute the net electrostatic force on p via the Barnes-Hut approximation and update p.acceleration accordingly.

Parameters
pThe particle for which to compute the force. Modified in-place.

The tree must already be populated (via build() / add_particle()). This function first calls eval() on the root to (re-)compute aggregate charges and centres-of-charge, then performs the recursive traversal.

Parameters
pThe particle for which to compute the acceleration. Modified in-place.
