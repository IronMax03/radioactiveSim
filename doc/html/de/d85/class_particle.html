void Particle::move ( double dt)

Move the particle by updating its position and velocity based on its acceleration and the time step dt.

Parameters
dtThe time step to move the particle. Must be positive and not equal to zero.
Exceptions
std::runtime_errorif dt is negative or zero.
Note
this error can be ignored whith a try catch if the final user wants to use a negative or zero time step.
This error is mainly here to prevent the user from accidentally using a negative or zero time step, which would lead to undefined behavior in the simulation.
